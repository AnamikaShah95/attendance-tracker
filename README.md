# 📋 Live Attendance Tracker

[![Python Version](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)

A lightweight desktop application built with Python and Tkinter that tracks real-time attendance, prevents duplicate entries, logs exact check-in timestamps, and exports data instantly to an Excel-friendly CSV spreadsheet.

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🖥️ **Desktop GUI** | Clean, user-friendly graphical interface powered by Tkinter. |
| 🛑 **Smart Validation** | Automatically blocks blank spaces and duplicate check-ins with popup warnings. |
| ⏱️ **Live Timestamps** | Tracks and attaches the exact time (`HH:MM:SS`) a person signs in. |
| 💾 **Excel Ready** | Alphabetically sorts and exports your data to a `daily_attendance.csv` file on close. |
